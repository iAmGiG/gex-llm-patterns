## Quick Start

### Volatility Spillover Analysis (Issue #181)

**Research Question**: Does UVXY GEX lead equity regime changes?

```bash
cd scripts/research/paper3
python volatility_spillover_analysis.py
```

**Output**:

- Granger causality test results (UVXY → SPY/QQQ/IWM)
- Rolling correlation stability metrics
- Regime transition predictors

**Expected Findings** (from preliminary AutoGen-Trader research):

- UVXY → SPY: r=0.157, p<0.0001, lag=1 day
- UVXY → QQQ: r=0.106, p<0.0001, lag=1 day
- UVXY → IWM: r=0.175, p<0.0001, lag=1 day

---

### Cross-Asset Correlation (Issue #182)

**Research Question**: How do correlations vary by regime state?

```bash
python cross_asset_correlation.py
```

**Output**:

- Correlation matrices by regime (persistent positive/negative/transitional)
- Lead-lag relationships across asset classes
- Regime persistence metrics

**Expected Findings**:

- QQQ correlations: Stable across regimes
- IWM correlations: Unstable (shift during transitions)
- Equity segments: Synchronized (lag=0)

---

### Hedge Ratio Optimization (Issue #184)

**Research Question**: What are optimal hedge ratios by regime?

```bash
python hedge_ratio_optimization.py
```

**Output**:

- Optimal portfolio weights by regime state
- Variance reduction metrics
- Dynamic vs static allocation comparison

**Expected Findings**:

- VXX variance reduction: 57.7%
- TLT variance reduction: 6.3%
- Dynamic Sharpe: 5.0 vs Static: 4.5 (+10%)

## Workflow

