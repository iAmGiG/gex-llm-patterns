**Comments 1.** In this paper, the temporal obfuscation testing as a
methodology for validating LLM structural reasoning in domain-specific
applications is presented and applying this framework to options dealer
gamma exposure (GEX) patterns, the detection is validated by using
2,221 evaluations (1,412 real windows plus 809 synthetic controls)
spanning 2020–2025. These studies have important theoretical value. I
recommend it to be published in JRFM.

**Response 1.** We thank the reviewer for their careful reading of the
manuscript and for the positive recommendation. We are grateful for
the confirmation that the temporal obfuscation framework and the scale
of the validation (2,221 evaluations across the 2020–2025 period)
contribute meaningful theoretical value to the field. No changes were
requested in this review, and none have been made in response.
