\section{Run Ledgers of the Local Runs}
\label{sup:ledger}

Tables~\ref{tab:s:led:oss}, \ref{tab:s:led:llama} and~\ref{tab:s:led:qwen} list the local runs of gpt-oss-20b, Llama~3.1~8B and Qwen3-8B (Section~3 of the article) and, below the total of each model, the variant runs (reasoning first, temperature 0), one row per chunk, with the requests, the tokens and the GPU time. The runs cost nothing. The hosted Batch runs of the companion manuscript (Paper A) are listed in its supplement and are not repeated here.
