\section{Schema Field Order}
\label{app:schema}

The answer is constrained by a strict JSON schema with nine required fields: \ident{regime_detected} (boolean), \ident{regime_type} (one of four strings), \ident{positive_days}, \ident{negative_days}, \ident{sign_flips} and \ident{confidence} (integers), \ident{avg_magnitude_billions} and \ident{persistence_pct} (numbers) and \ident{reasoning} (string). The prompt and the complete schema are those of Paper A (Appendix~A of the companion manuscript \cite{regan2026rerun}) and of the stored requests; the deposit holds every request. vLLM decodes the fields in the order of the schema. The runs of this paper use two orders.

For gpt-oss-20b and Qwen3-8B the reasoning channel of the model ends before the JSON object starts (the reasoning parsers of vLLM separate it), so these models have reasoned before they write any field, whatever the order of the schema.
