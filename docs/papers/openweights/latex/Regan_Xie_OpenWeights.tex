\abstract{When a hosted model is retired, an LLM evaluation built on it can no longer be run again, and its successor alias may change in turn. Can it be reproduced with open-weights models, run locally at pinned revisions on the stored requests? The task is a rule stated in the prompt: three thresholds decide whether a 30-day window of obfuscated daily SPY gamma exposure is a persistent regime. Agreement with the rule is the object of study, not a claim about reasoning. gpt-oss-20b, Llama 3.1 8B and Qwen3-8B answered seven arms (47,176 requests, 111.8 GPU-hours). gpt-oss-20b gives the stored o4-mini verdict in 99.6\% of 1,412 windows and agrees with the rule in 99.7\% of the 4,689 windows of the complete series that it answers. Qwen3-8B agrees in 98.7\% of the windows it answers, but 8.8\% of all windows stay unanswered, so its 2024--2025 rate is bounded at 14.5--35.1\%. Llama 3.1 8B writing its verdict first detects almost every window (kappa 0.000); with the reasoning first it does not, but still does not follow the rule (kappa 0.096). Temperature 0 changes neither the gpt-oss-20b nor the Llama result on the published inputs.}
