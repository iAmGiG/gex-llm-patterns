A retired hosted model leaves its answers but not its evaluation. We asked whether the evaluation can be run again with open-weights models at pinned revisions on the stored requests. For a rule stated in the prompt, it can, for two of three models. gpt-oss-20b gives the stored o4-mini verdict in 99.6\% of 1{,}412 windows and agrees with the rule in 99.7\% of the windows of the complete series, and Qwen3-8B agrees with it in 98.7\% of the windows that it answers. The price of reproduction is not money but unfinished answers and GPU time: Qwen3-8B left 8.8\% of the windows unanswered, mostly windows that the rule rejects, so its 2024--2025 rate is bounded at 14.5\% to 35.1\%, and the three models used 111.8 GPU hours on shared GPUs. Llama~3.1~8B, which writes its verdict before any reasoning, detects almost every window. \pending{D-33, D-34: one sentence on the reasoning-first and temperature-0 runs.} Agreement with the rule is evidence that a model applies stated criteria; it says nothing about reasoning without them. We recommend that studies built on hosted models store every request, pin a local model and its engine, record the sampling defaults, and report the windows that a model does not answer.
