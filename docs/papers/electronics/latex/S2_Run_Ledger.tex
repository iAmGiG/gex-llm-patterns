Tables~\ref{tab:ledger3} and~\ref{tab:ledger4} list the local runs of the open-weights models gpt-oss-20b and Llama~3.1~8B (Section~3.5 of the article), which cost nothing. The arms are defined in Section~3.6 of the article.
